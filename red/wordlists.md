# 📂 Повна структура, архітектура та робота з пакетами Wordlists (Arch Linux / `yay -S wordlists`)

Ця документація описує повну структуру, призначення та просунуті техніки роботи зі словниками, які розгортаються системою під час встановлення пакету `wordlists` (або аналогічних збірок у Kali/BlackArch).

---

## 🏗️ Загальна структура в системі
Після встановлення всі архіви розпаковуються у стандартну системну директорію:
```bash
/usr/share/wordlists/
```
> **💡 Порада:** Багато утиліт очікують знайти легендарний словник `rockyou.txt` саме тут. Часто він стиснутий (`rockyou.txt.gz`). Розпакуйте його одразу після встановлення: `sudo gunzip /usr/share/wordlists/rockyou.txt.gz`.

Нижче наведено детальний опис кожного компонента, його структури та просунутих сценаріїв використання.

---

## 1. 🌐 SecLists (`danielmiessler/SecLists`)
**Що це таке:** Найбільший і найповніший репозиторій словників для безпеки у світі. Це стандарт де-факто для будь-якого пентестера.

* **Де шукати в системі:** `/usr/share/wordlists/seclists/`
* **Повна структура головних директорій:**
  * **`Discovery/`** — розвідка та пошук прихованих ресурсів:
    * `Web-Content/` — гігантська база для вебфаззингу (`directory-list-2.3-medium.txt`, `common.txt`, `raft-large-directories.txt`). Також містить специфічні списки під CMS (WordPress, Joomla) та технології (Tomcat, Nginx, Spring, API).
    * `DNS/` — словники для брутфорсу субдоменів (`subdomains-top1million-5000.txt`, `bitquark-subdomains-top100000.txt`).
    * `Infrastructure/` & `SNMP/` — пошук мережевих пристроїв, роутерів та ком'юніті-стрінгів SNMP (`snmp-onesixtyone.txt`).
    * `Variables/` — назви типових змінних та параметрів для пошуку прихованих GET/POST параметрів (`secret`, `debug`, `id`, `token`).
  * **`Passwords/`** — гігантські словники паролів:
    * `Common-Credentials/` — топ найпопулярніших паролів (`10-million-password-list-top-10000.txt`), паролі за замовчуванням (`default-passwords.csv`).
    * `Leaked-Databases/` — реальні витоки (включно з `rockyou`, `AshleyMadison`, `NordVPN` тощо).
    * `Default-Credentials/` — заводські логіни:паролі для специфічного обладнання та софту (SSH, FTP, Telnet, бази даних, роутери Cisco/MikroTik).
    * `WiFi-WPA/` — словники, відфільтровані за вимогами WPA (довжина від 8 символів).
  * **`Usernames/`** — списки логінів для перебору користувачів (`top-usernames-shortlist.txt`, імена з баз MIT, специфічні системні імена типу `root`, `postgres`, `admin`).
  * **`Fuzzing/`** — набори корисного навантаження (payloads) для пошуку вразливостей:
    * `SQLi/`, `XSS/`, `LFI/` (Local File Inclusion — наприклад, `LFI-Jhaddix.txt`), `SSRF/`, `XXE/`, `Command-Injection/`.
    * Специфічні формати: обхід фільтрів, спецсимволи, юнікод, форматні рядки.
  * **`Pattern-Matching/`** та **`Miscellaneous/`** — регулярні вирази для пошуку секретів у коді та допоміжні файли (User-Agents, розширення файлів).

## 2. 🔍 Wfuzz (`xmendez/wfuzz`)
**Що це таке:** Словники, створені спеціально під потужний вебфаззер `wfuzz` (також ідеально підходять для сучасного та швидкого `ffuf`). Вони оптимізовані для підстановки параметрів (`FUZZ` мітки) у запитах.

* **Де шукати в системі:** `/usr/share/wordlists/wfuzz/`
* **Головні папки та за що вони відповідають:**
  * **`general/`** — базові слова, мутації та комбінації (`common.txt`, `medium.txt`, `megabeast.txt`).
  * **`injections/`** — концентровані списки для перевірки на ін'єкції (`SQL.txt`, `XSS.txt`, `Traversal.txt`, `All_attack.txt`).
  * **`webservices/`** — специфічні шляхи для WS, SOAP, REST API.
  * **`others/`** — списки розширень файлів, методів HTTP та заголовків.
  * **`vulns/`** — специфічні перевірки під конкретні сервери (Apache, IIS, ColdFusion, CGIs).

---

## 3. 📂 Dirb (`kalilinux/packages/dirb`)
**Що це таке:** Класичний і перевірений роками набір словників від сканера `dirb`. Невеликі за розміром, але надзвичайно ефективні для швидкої розвідки завдяки ретельному відбору слів.

* **Де шукати в системі:** `/usr/share/wordlists/dirb/`
* **Головні папки та файли:**
  * **`common.txt`** (~4600 рядків) — найважливіший файл для старту. Містить найпоширеніші шляхи (`admin`, `login`, `config`, `.git/HEAD`, `robots.txt`).
  * **`big.txt`** (~20 000 рядків) — розширена версія для глибшого сканування.
  * **`small.txt`** (~950 рядків) — ультрашвидка перевірка.
  * **`extensions_common.txt`** — список найчастіших розширень файлів (`.php`, `.html`, `.bak`, `.zip`, `.old`).
  * **`vulns/`** — специфічні шляхи для пошуку старих, але критичних вразливостей у популярних серверах.

---

## 4. 🚀 DirBuster (`kalilinux/packages/dirbuster`)
**Що це таке:** Словники від графічного інструменту OWASP DirBuster. Вони збиралися шляхом парсингу реального інтернету (павуками) і розташовані за частотою використання.

* **Де шукати в системі:** `/usr/share/wordlists/dirbuster/`
* **Головні файли:**
  * `directory-list-2.3-small.txt` (~87 тис. слів) / `medium.txt` (~220 тис. слів) — регістрозалежні (case-sensitive) списки.
  * `directory-list-lowercase-2.3-small.txt` / `medium.txt` — ті ж самі списки, але переведені в нижній регістр (незамінні для серверів на Windows/IIS, яким байдуже на регістр, щоб не робити подвійну роботу).
  * `apache-user-enum-1.0.txt` / `2.0.txt` — словники для перебору імен користувачів через модуль Apache `mod_userdir` (`/~username`).

## 🛠️ 5. Генерація власних словників та мутації (Просунутий рівень)
Стандартних словників недостатньо, коли ціль використовує специфічну політику паролів або корпоративні назви. Тоді словники створюють «на льоту».

### А. Таргетований збір слів з сайту (`CeWL`)
Утиліта `cewl` сканує сайт компанії та збирає всі унікальні слова (назви проектів, імена, терміни), з яких люди зазвичай і складають свої паролі.
```bash
cewl -d 2 -m 5 -w custom_company_words.txt https://target-company.com
```
*(де `-d 2` — глибина парсингу, `-m 5` — мінімальна довжина слова 5 символів)*.

### Б. Генерація за маскою (`Crunch`)
Якщо ви знаєте структуру пароля (наприклад, слово `admin` + 4 цифри року), генеруйте точний список через `crunch`:
```bash
crunch 9 9 -t admin%%%% -o admin_years.txt
```
*(Позначення у crunch: `@` — малі літери, `,` — великі літери, `%` — цифри, `^` — спецсимволи).*

### В. Правила трансформації (Rules у `Hashcat` / `John the Ripper`)
Замість того, щоб зберігати терабайти словників із мутаціями (типу `password`, `P@ssw0rd123`, `Password2024!`), пентестери беруть базовий словник і застосовують до нього **правила (Rules)** безпосередньо під час зламу:
* Правило **`best64.rule`** — додає найпопулярніші закінчення (цифри, `!`, роки), змінює першу літеру на велику, робить заміни (`a` -> `@`, `o` -> `0`).
* Приклад генерації мутованого словника через Hashcat для використання в інших програмах:
  ```bash
  hashcat --force password_base.txt -r /usr/share/hashcat/rules/best64.rule --stdout > mutated_passwords.txt
  ```

## 💡 Резюме: Повний алгоритм дій для команди

1. **Етап 1 (Швидка розвідка вебу - 1-2 хв):** 
   Запускаємо `ffuf` або `gobuster` зі словником `dirb/common.txt` (додаючи розширення `.php,.txt,.bak,.zip`).
2. **Етап 2 (Глибокий пошук директорій - 10-30 хв):** 
   Використовуємо `SecLists/Discovery/Web-Content/raft-large-directories.txt` або `dirbuster/directory-list-2.3-medium.txt`.
3. **Етап 3 (Пошук субдоменів та віртуальних хостів):** 
   Використовуємо `SecLists/Discovery/DNS/subdomains-top1million-20000.txt`.
4. **Етап 4 (Фаззинг параметрів та ін'єкцій):** 
   Для пошуку імен прихованих параметрів — `SecLists/Discovery/Web-Content/burp-parameter-names.txt`. Для перевірки знайденого параметра на вразливості — папка `wfuzz/injections/` або `SecLists/Fuzzing/`.
5. **Етап 5 (Брутфорс авторизації: SSH, FTP, Вебформи):** 
   * Починаємо зі списків за замовчуванням: `SecLists/Passwords/Default-Credentials/`.
   * Якщо не підійшло — генеруємо власний словник через `CeWL` із сайту жертви.
   * Останній рубіж (для офлайн-хешів) — важка артилерія `rockyou.txt` у парі з правилами мутації `best64.rule`.
