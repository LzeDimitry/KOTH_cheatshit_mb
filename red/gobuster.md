# 🚀 Gobuster: Повний довідник та шпаргалка (Без води)

Ця документація містить повний розбір можливостей **Gobuster** — одного з найшвидших сканерів на мові Go. Тут зібрані всі режими роботи (від пошуку папок до віртуальних хостів і хмарних бакетів) та критичні прапорці для реального пентесту і CTF.

---

## 🏗️ 0. Архітектура: Головні режими роботи
Gobuster — це модульний інструмент. Першим словом після `gobuster` завжди вказується **режим**:

* **`dir`** — класичний пошук прихованих директорій та файлів на вебсервері.
* **`vhost`** — пошук віртуальних хостів (коли на одній IP-адресі висить декілька сайтів, наприклад `dev.target.htb`, яких немає в глобальному DNS).
* **`dns`** — брутфорс субдоменів через прямі DNS-запити.
* **`fuzz`** — універсальний режим фаззингу (підстановка слів замість ключового слова `FUZZ` у будь-якому місці запиту).
* **`s3` / `gcs`** — пошук відкритих хмарних сховищ Amazon S3 та Google Cloud Storage.

---

## 📁 1. Режим `dir`: Пошук папок та файлів

### А. Автоматичне додавання розширень (`-x`) та слешів (`-f`)
Якщо ти шукаєш не просто папки, а конкретні скрипти, бекапи чи конфігурації, Gobuster сам підставлятиме розширення до кожного слова зі словника.

* **`-x` (`--extensions`)** — список розширень через кому.
* **`-f` (`--add-slash`)** — примусово додає `/` в кінці кожного слова (деякі сервери або фреймворки реагують на `/admin/` інакше, ніж на `/admin`).
* **Приклад (Java / Tomcat):**
  ```bash
  gobuster dir -u http://192.168.1.114:8082 -w /usr/share/wordlists/dirb/common.txt -x jsp,html,txt,bak,zip -t 50
  ```
  *(Якщо у словнику є слово `admin`, сканер за один прохід перевірить `/admin`, `/admin.jsp`, `/admin.bak` і т.д.)*

### Б. Робота зі статус-кодами (`-b` та `-s`) — Важливий нюанс!
За замовчуванням Gobuster ігнорує код `404` (через базове налаштування `-b 404`). 

* **`-b` (`--exclude-status`)** — чорний список (які коди ховати).
  * *Приклад:* `-b 404,403,500`
* **`-s` (`--status-codes`)** — білий список (показувати **тільки** ці коди).
  * ⚠️ **Критичне правило:** У нових версіях Gobuster не можна просто написати `-s 200,301`, бо виникне конфлікт із базовим чорним списком `-b 404`. Щоб увімкнути `-s`, потрібно **обов'язково очистити `-b`**, передавши порожні лапки `-b ""`:
  ```bash
  gobuster dir -u http://192.168.1.114 -w common.txt -s 200,204,301,302,401 -b ""
  ```

### В. Фільтрація «хибних спрацьовувань» за розміром (`--exclude-length`)
Сучасні сайти (SPA, роутери) часто повертають код `200 OK` на будь-яку неіснуючу сторінку, пишучи текстом «Сторінку не знайдено». Оскільки розмір цієї кастомної помилки завжди однаковий (наприклад, 2576 байт), її легко відфільтрувати.

* **`--exclude-length`** — ігнорувати відповіді певного розміру (можна вказувати діапазони та декілька значень).
* **Приклад:**
  ```bash
  gobuster dir -u http://192.168.1.114:8082 -w common.txt --exclude-length 2576,500-520
  ```

### Г. Робота з HTTPS, Редіректами та Метод запиту
* **`-k` (`--no-tls-validation`)** — **Мастхев!** Ігнорує помилки SSL/TLS-сертифікатів. Без нього Gobuster відмовиться сканувати будь-який `https://` сервер із самопідписаним сертифікатом.
* **`-r` (`--follow-redirect`)** — автоматично переходити за редіректами (`301` / `302`).
* **`-m` (`--method`)** — змінити HTTP-метод (наприклад, `-m POST` замість стандартного `GET`).

## 🔐 2. Авторизація, Сесії, Заголовки та Проксі

Часто найцікавіші файли сховані всередині панелі керування, куди пускає лише після логіну.

* **`-c` (`--cookies`)** — передача сесійних куків (щоб сканувати від імені залогіненого користувача).
  ```bash
  gobuster dir -u http://192.168.1.114/dashboard/ -w common.txt -c "PHPSESSID=a1b2c3d4e5; security=low"
  ```
* **`-H` (`--header`)** — додавання будь-яких кастомних HTTP-заголовків (JWT-токени, специфічні API-ключі, обхід простих фільтрів). Можна використовувати кілька разів.
  ```bash
  gobuster dir -u http://192.168.1.114 -w common.txt -H "Authorization: Bearer eyJhbG..." -H "X-Forwarded-For: 127.0.0.1"
  ```
* **`-a` (`--useragent`)** — швидка зміна User-Agent (щоб не світити стандартний `gobuster/3.x` у логах захисту).
* **`-U` та `-P`** — логін і пароль для базової HTTP-автентифікації (Basic Auth):
  ```bash
  gobuster dir -u http://192.168.1.114/manager/ -w common.txt -U admin -P s3cret
  ```
* **`--proxy`** — направити весь трафік через проксі (ідеально, щоб автоматично наповнити карту сайту в **Burp Suite** або працювати через SOCKS5-тунель):
  ```bash
  gobuster dir -u http://192.168.1.114 -w common.txt --proxy http://127.0.0.1:8080 -k
  ```

## 🌐 3. Інші бойові режими: `vhost`, `dns`, `fuzz`, `s3`

### А. Режим `vhost` (Пошук прихованих сайтів на одному сервері)
Підміняє заголовок `Host: <слово>.target.htb` у запитах до одного й того ж IP. Незамінний на CTF (HackTheBox, TryHackMe) та внутрішніх пентестах.
* ⚠️ **Важливий прапорець:** `--append-domain` — змушує Gobuster автоматично дописувати базовий домен до кожного слова зі словника.
```bash
gobuster vhost -u http://target.htb -w /usr/share/wordlists/seclists/Discovery/DNS/subdomains-top1million-5000.txt --append-domain --exclude-length 154
```

### Б. Режим `dns` (Пошук публічних субдоменів)
Запитує DNS-сервери, чи існують записи для піддоменів.
* **`-d`** — цільовий домен.
* **`-i` (`--show-ips`)** — одразу показувати IP-адреси знайдених субдоменів.
* **`-r` (`--resolver`)** — вказати кастомний DNS-сервер (наприклад, `1.1.1.1` або внутрішній контролер домену `10.10.10.5:53`).
```bash
gobuster dns -d google.com -w subdomains-top1million-5000.txt -i -r 1.1.1.1 -t 50
```

### В. Режим `fuzz` (Фаззинг параметрів)
Замінює слово `FUZZ` у URL, заголовках або тілі запиту на слова зі словника (аналог `wfuzz` та `ffuf`).
```bash
gobuster fuzz -u "http://192.168.1.114/index.php?file=FUZZ" -w /usr/share/wordlists/seclists/Fuzzing/LFI/LFI-Jhaddix.txt -b 404,403
```

### Г. Режим `s3` (Пошук хмарних бакетів AWS)
Перевіряє існування та права доступу до бакетів Amazon S3 за ключовими словами компанії.
```bash
gobuster s3 -w bucket_names.txt
```

## ⚙️ 4. Керування швидкістю, Виводом та Таймаутами

* **`-t` (`--threads`)** — кількість одночасних потоків (за замовчуванням `10`). Для локальних мереж сміливо став `-t 50` або `-t 100`.
* **`--delay`** — пауза між запитами в одному потоці (наприклад, `--delay 200ms`). Рятує, коли сервер має Rate Limiting або WAF і блокує за швидкий перебір.
* **`--timeout`** — час очікування відповіді від сервера (за замовчуванням `10s`).
* **`-o` (`--output`)** — зберегти результати у файл (`-o gobuster_results.txt`).
* **`-e` (`--expanded`)** — друкувати повний URL у результатах (`http://target.com/admin` замість просто `/admin`).
* **`-q` (`--quiet`)** — прибрати банер та зайве оформлення (зручно для передачі виводу в інші скрипти).
* **`--no-error`** — не засмічувати екран помилками про таймаути з'єднання.

## 💡 Золотий стандарт: 3 готові команди на щодень

**1. Швидка розвідка вебсервера (з розширеннями, ігноруванням SSL та чистим виводом):**
```bash
gobuster dir -u https://192.168.1.114:8443 -w /usr/share/wordlists/dirb/common.txt -x php,txt,bak,zip,old -t 50 -k -e --no-error -o dir_scan.txt
```

**2. Сканування з фіксацією лише потрібних кодів (правильний обхід конфлікту `-s` та `-b`):**
```bash
gobuster dir -u http://192.168.1.114 -w /usr/share/wordlists/seclists/Discovery/Web-Content/raft-medium-directories.txt -s 200,204,301,302,401 -b "" -t 50
```

**3. Пошук прихованих піддоменів (VHosts) на локальному сервері / CTF:**
```bash
gobuster vhost -u http://target.htb -w /usr/share/wordlists/seclists/Discovery/DNS/subdomains-top1million-5000.txt --append-domain -t 50 -k
```
